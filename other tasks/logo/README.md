# Логотип ПЛЮСОН для конференций

Конференц-локап: знак + «ПЛЮСОН» + подпись «от iViSiON». Нужен для выступлений,
где ПЛЮСОН выступает партнёром события.

Утверждено 16.09.2026.

Исходники знака: `logo_no_ivision_wwhite.png` (белый) и `logo_no_ivision_blue.png` (синий).

## HTML-файлы — это спецификация, а не просто превью

В каждом HTML **в комментарии вверху записаны все параметры**: шрифты, кегли,
размеры знака, зазоры, точные стопы градиентов и команда для пересборки PNG.
Плюс под каждой картинкой на самой странице — её полная спецификация.

Правило: **одна картинка — одно полное описание**. Никаких отсылок вида
«как в тёмной версии» — каждый файл самодостаточен, даже если параметры
повторяются.

| Файл | Что описывает |
|---|---|
| `plusson_logo_dark.html` | Горизонтальный локап для тёмного фона |
| `plusson_logo_light.html` | Горизонтальный локап для светлого фона |
| `plusson_logo_vertical.html` | Вертикальная компоновка, обе версии |

## Ключевые решения — коротко

**Шрифты.** «ПЛЮСОН» — Oswald 600, трекинг `0.055em`. «от iViSiON» — Roboto 500,
**прямое начертание** (не курсив), трекинг `0.01em`.

**Размеры** (базовые, при кегле «ПЛЮСОН» 52 px): подпись 16 px, знак 92 px
в горизонтальной версии и 110 px в вертикальной. Знак на 20 % выше блока букв.

**Выравнивание.** В горизонтальной версии правые края «ПЛЮСОН» и «iViSiON»
стоят на одной вертикали. Для этого нужна компенсация: `letter-spacing`
добавляет отступ и **после последней буквы**, поэтому у каждой строки
`margin-right: -(кегль × трекинг)`. Без неё края расходятся примерно на 3 px.

**Два разных градиента — это принципиально.**

- **Тёмный фон:** инверсия с бликом, 12 стопов. Блик `#FFDEBC` вынесен к краям
  буквы, тень `#A87850` сидит внутри — буква выглядит гранёной.
- **Светлый фон:** блика нет, диапазон уплотнён, 8 стопов. На белом блик
  физически не работает (светлее белого ничего нет — светлая полоса читается
  как дырка в букве), а чистый персиковый `#FFCFA4` даёт контраст с белым
  всего 1.3:1 и буквы тают. Самая тёмная точка `#A87244` даёт 4.1:1.

Оба градиента идут под углом `45deg`.

## Что уже пробовали и отвергли

Записано, чтобы не наступить второй раз.

| Пробовали | Почему отказались |
|---|---|
| Блик `#FFF2E2` на тёмном | Почти белый — буквы выглядели выбеленными |
| Один перелив вместо двух | Читалось как сплошная заливка, отлива не видно |
| Тени `#8A5A2E` / `#A06A38` на светлом | Кирпично и агрессивно, от персикового не остаётся следа (контраст 5.9:1) |
| Тень `#8E5C33` на светлом | 5.6:1 — практически то же самое, та же проблема |
| `drop-shadow` вместо уплотнения цвета | Буква остаётся бледной, под ней лишь ореол. При офсете мягкая тень рассыпается в точку и читается как грязь; на цветной подложке ореол чужероден |
| Градиент снизу вверх (180°) | Некрасиво |
| Oswald «курсивом» | У Oswald нет настоящего курсива — только искусственный наклон, выглядит дёшево |
| Курсив у подписи «от iViSiON» | Пробовали во всех компоновках, отказались 16.09.2026 — решили оставить прямое начертание |

## Как пересобрать PNG

Нужен Chrome. На macOS:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --disable-gpu --default-background-color=00000000 \
  --hide-scrollbars --window-size=2400,700 \
  --screenshot=out.png file:///путь/к/файлу.html
```

Затем обрезать по содержимому (Pillow):

```python
from PIL import Image
im = Image.open('out.png').convert('RGBA')
l, t, r, b = im.getbbox()
im.crop((max(0,l-2), max(0,t-2), min(im.width,r+2), min(im.height,b+2))).save('final.png')
```

Для отрисовки в HTML-файлах ставится `--scale: 4` — при кегле 208 px буквы
не пикселят.

## Открытый вопрос

Исходники знака небольшие: 201 × 164 px и 181 × 149 px. Для баннеров и
крупной полиграфии края пятиугольника замылятся. **Если найдётся SVG или
крупная растровая версия знака — PNG стоит пересобрать с ней.**
