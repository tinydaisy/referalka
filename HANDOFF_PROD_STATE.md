## 3. ⚠️⚠️ ГЛАВНОЕ: event_page_html.py + миграция 174 (chat_ref) — конфликт

**Симптом:** страница `pluson.ru/event/{slug}` падает с 500:
`column events.vk_chat_ref does not exist`.

**Причина:** дев-коммит `a7b5e99` переписал в `event_page_html.py` чтение чатов
события на `tg_chat_ref / vk_chat_ref / max_chat_ref` (подзапросы к
client_broadcast_chats). Эти колонки создаёт **дев-миграция 174 (event_chat_refs)**,
которая на ПРОДЕ НЕ накатана (проверено: 0 колонок vk_chat_ref в events).

**Сейчас (08:50) страница отдаёт 200 ТОЛЬКО потому, что api в памяти на старой версии
и не перезапускался после webhook-pull дева. Любой `systemctl restart plusson-api`
или деплой бэка → страница упадёт 500.**

**Что делать при переносе дева на прод (ПРАВИЛЬНЫЙ путь):**
1. НАКАТИТЬ миграцию 174 (`db/migrations/174_event_chat_refs.sql`) на прод-БД
   ДО рестарта api. Она создаёт tg/vk/max_chat_ref в events + переносит данные.
   ⚠️ Проверь GRANT-ы для роли `plusson` после миграции.
2. Потом рестартить `plusson-api plusson-celery plusson-celery-beat` (+ bot если надо).
3. Только после этого страница /event/{slug} заработает на новом коде.

**Текущее грязное состояние файла на проде:** `git status` показывает
`event_page_html.py` как modified — это мои РУЧНЫЕ python-патчи прямо на проде поверх
дев-версии (я чинил 500 вслепую). Там сейчас СМЕСЬ: и мой `stage-box`, и дев `chat_ref`.
**НЕ полагайся на содержимое файла на проде — сделай `git checkout
backend/app/api/event_page_html.py` (вернёт к HEAD=a7b5e99, чистая дев-версия), затем
накати миграцию 174 — и всё сойдётся.** Мои правки страницы (евро-даты, прочерк) уже
в коммитах `45bb4b3`/`0c95549` в истории до `a7b5e99` — НО дев `a7b5e99` мог их
перетереть в этом файле. После checkout проверь, остались ли в файле: евро-даты
(`_fmt_date_eu`), отсутствие прочерка у пустого дня. Если дев перетёр — нужно их
вернуть (см. раздел 4).

## 5. Webhook автодеплоит web на push в main

`plusson-webhook.service` на push в main делает git pull + пересборку plusson-web.
Бэкенд/миграции/mini-app webhook НЕ трогает. Поэтому мои фронт-коммиты программы
турнира уже на проде (web пересобран). Если будешь пушить — помни: web уедет сам,
бэк и миграцию 174 накатывай вручную и желательно РАНЬШЕ web.
