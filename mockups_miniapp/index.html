ПЛЮСОН

Mini App — все макеты

Папка mockups_miniapp/. Стиль иконок — персиковые на тёмном / синие на персиковом, единый icons.css. Логика общих вкладок — в shared_tabs, чтобы не править одно и то же в каждом файле.
Общие вкладки события
Игра, Окно подарков, Розыгрыш, Экосистема, Итоги. Одинаковы для мероприятия, конференции и других типов.
Источник правды
Хаб организатора
Календарь — лента событий клиента (LIVE / Скоро / Прошедшие). Открывается из своего бота клиента или когда у участника один организатор.
Селектор события
Список «Ваши события» когда участник у нескольких клиентов в общем @pluson_bot. Вкладка «ПЛЮСОН» — рекламная, для приглашения новых клиентов.
Мероприятие
Лендинг + Программа для базового события (вебинар, нетворкинг, мастер-класс). Без VIP, без чата, простая программа.
Конференция
Расширенный модуль: программа по дням со спикерами, VIP-тариф, чат конференции (за подписку), горизонтальный скролл партнёров.
Все макеты — кликабельные превью. Реальный код будет в mini-app/src/ с теми же визуальными решениями.
